How to Extract Text From an Image with OCR

Learn how OCR turns text inside screenshots, scans, and photos into editable text and how to improve recognition quality.

What is OCR?

OCR, or optical character recognition, analyzes an image and attempts to identify the characters shown in it. It is useful for scanned pages, screenshots, photographed documents, and other images containing text.

How to get better OCR results

  • Use a sharp, well-lit image.
  • Keep text upright when possible.
  • Avoid heavy blur, compression artifacts, or decorative backgrounds.
  • Crop away unrelated areas when they confuse recognition.

Image OCR vs PDF text extraction

If a PDF already contains selectable text, direct text extraction is usually more appropriate. If each page is essentially a scan, OCR may be required.
